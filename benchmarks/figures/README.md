# Benchmark figure code

This directory contains only plotting code for current benchmark schemas and the shared publication style. Numerical runs and plotting are intentionally separate.

The final manuscript composition is governed by `../FIGURES.md`. Component plotting modules are retained for inspecting scaling and memory outputs, but the final multi-panel manuscript figures are assembled only after the complete publication dataset and `CLAIMS.md` audit are finished. Historical/pre-consolidation figure builders live under `benchmarks/development/` and are not manuscript sources.
