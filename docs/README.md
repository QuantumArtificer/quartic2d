# QUARTIC2D documentation

Install the documentation dependencies and build from the repository root with

```bash
python -m pip install -e ".[docs,ogata]"
python docs/scripts/generate_figures.py examples
python docs/scripts/generate_example_artifacts.py
python docs/scripts/check_artifacts.py
python -m sphinx -W --keep-going -b html docs/source docs/_build/html
python docs/scripts/check_rendered_docs.py docs/_build/html
```

The final command checks internal links and anchors, local image assets, image alternative text, duplicate HTML IDs, and documentation regression guards. Visual QA should still inspect representative desktop and narrow/mobile pages for equation, table, code-block, figure, caption, navigation, and API-reference layout.

A clean build ends with

```text
build succeeded.
```

The documentation is organized as Getting Started, User Guide, API Reference, Guided Examples, Theory, Limitations and Scope, Validation and Benchmarks, References, and Development. Tutorial pages contain executable code, representative terminal output, equations, and figures. Exact signatures and parameter contracts live in the object-oriented API reference, where each public class and callable method has its own page.

Guided-example terminal output and convergence diagnostics are generated by executing the example scripts themselves:

```bash
python docs/scripts/generate_example_artifacts.py
```

The remaining tutorial figures are regenerated with:

```bash
python docs/scripts/generate_figures.py examples
```

Publication validation figures and generated numerical tables require the canonical benchmark bundle, which is intentionally not stored in the source tree:

```bash
python docs/scripts/regenerate_publication_evidence.py \
    --results-dir /path/to/canonical-results
```

The tracked validation figures/tables are derived snapshots. Their source-bundle fingerprint is recorded in the generated metadata and validation SVGs. Check the tracked artifact contract at any time with

```bash
python docs/scripts/check_artifacts.py
```

Supplying `--results-dir` additionally verifies that the tracked validation snapshot belongs to that exact benchmark bundle. None of these commands reruns the publication benchmark suite.

The GitHub Actions documentation workflow builds the same source with warnings treated as errors and deploys the `main` branch to GitHub Pages.
