# Examples

- `hankel_gaussian.py`: sampled Gaussian Hankel transform with an analytic reference.
- `petal2d_harmonics.py`: PETAL2D harmonics transformed with the default Quartic2D settings.
- `petal2d_full_workflow.py`: decomposition figures, transform diagnostics, convergence tables, and convergence figures.
- `gaussian_interaction.py`: complete interaction workflow for an isotropic Gaussian density.
- `anisotropic_interaction.py`: angular dependence and harmonic-resolved interaction contributions.
- `quadrature_backends.py`: quadrature, interpolation, and interaction backends.
- `convergence.py`: explicit parameter convergence for PETAL2D harmonic transforms.
